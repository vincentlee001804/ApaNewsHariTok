# Benchmark Artifacts — Summary-Length Consistency

Generated by `scripts/benchmark_summaries.py`. Do not hand-edit raw outputs; they are evidence.

## How to reproduce

```powershell
python scripts/benchmark_summaries.py export --n 50 --seed 42
python scripts/benchmark_summaries.py run --models llama3.1 qwen2.5:3b ministral-3:8b-cloud
```

Files in this folder:

- `articles_fixture.json` — the fixed article sample (identical inputs for every model run).
- `run_<timestamp>.csv` — per-article, per-model raw outcomes (word counts, retry behavior, latency, final text).
- `metrics_<timestamp>.json` — aggregated metrics per model.
- `results.md` — human-readable summary table (copy of the latest metrics, with notes).
